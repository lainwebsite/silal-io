# Homepage Concept 3 — "From Desert to Discovery"

Static HTML (no build needed). Live: https://silal-io.vercel.app/homepage-concept-3

- `public/homepage-concept-3/index.html` — latest Concept 3 (journey panel, curved curtains, eased numbers, redesigned footer). Live at https://silal-io.vercel.app/homepage-concept-3.
- `public/homepage-concept-3/v1/index.html` — same page with the client's footer design. Live at https://silal-io.vercel.app/homepage-concept-3/V1.
- `public/homepage-concept-3/media/` — images and video for both.
- `public/brand/` — logo + favicon.
- `next.config.ts` — copy of the site config; its `rewrites()` map these files to the URLs above.

Open locally: serve `public/` as the web root (e.g. `npx serve public`) and go to `/homepage-concept-3/`.
